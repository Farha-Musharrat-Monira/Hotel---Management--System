# Hotel Management System

## Project Overview
This project is a hotel network design created using Cisco Packet Tracer. It represents a computer network for connecting different departments of a hotel.

## Objectives
- To design a network for a hotel.
- To connect different hotel departments.
- To enable communication between network devices.
- To create an organized and reliable network.

## Tools Used
- Cisco Packet Tracer

## Project File
**File Name:** `HOTEL MANAGEMENT SYSTEM.pkt`

The Packet Tracer project file is included in this repository.

## How to Open
1. Download the `.pkt` file from this repository.
2. Open Cisco Packet Tracer.
3. Go to File → Open.
4. Select the downloaded project file.
